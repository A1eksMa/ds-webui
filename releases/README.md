# Changelog

Архивы в этой папке — рабочая версия сайта (без `docs/` и dev-инструментов), готовая к
распаковке и открытию. Имя архива содержит номер версии: `ds-webui-<version>.tar.gz`.
Он же — в `<meta name="version">` внутри `index.html`.

Для машины без git: скачать один архив вместо файлов по отдельности.

## Распаковка

```bash
mkdir -p /path/to/target/folder
tar -xzf ds-webui-<version>.tar.gz -C /path/to/target/folder
```

Внутри: `index.html`, `app.js`, `styles.css`, `presets.js`, `sample-data/`, `scripts/`,
`LICENSE`, `README.md`.

## Запуск

Открыть `index.html` в браузере (двойной клик). Ничего ставить не нужно, сеть не требуется.
Пока рядом нет каталога `data/` (вывод `ds-loader` / поллера), страница показывает
закоммиченный `sample-data/`.

`scripts/` — макросы офисного пакета для выгрузки листа в JSON под `ds-loader`
(см. `scripts/README.md`). `docs/contract.md` и `tools/gen_sample.py` в архив не входят —
они только в репозитории.

## 0.3.0a1 — `ds-webui-0.3.0a1.tar.gz`

Условия выборки в «Конструкторе» вместо подстрочных базовых фильтров.

- Блок **«Условия»**: строки `поле · оператор · значение`, добавляются кнопкой `+ условие`,
  количество любое (в т.ч. ноль), каждая удаляется `✕`. Поле — из уже выбранных на первом
  шаге показателей.
- Операторы: `contains`, `not_contains`, `eq`, `ne`, `starts`, `ends`, `gt`, `gte`, `lt`,
  `lte` (числовое сравнение; пустая ячейка не подходит), `empty`, `not_empty` (значение не
  нужно, поле ввода блокируется). Строковые — без учёта регистра.
- Применяются **при построении датасета**, последовательно (И) — на «Таблицу» уходит уже
  суженный массив. Пофакторные фильтры в шапке таблицы — поверх, как и раньше.
- Хранятся в пресете как `view.conditions: [{field, op, value}]`. Прежнее
  `view.column_filters` при загрузке пресета мигрирует в `conditions` (оператор `contains`).
- `app.js` (matchCondition / applyConditions / normalizeConditions / reducer / конструктор),
  `styles.css`, `presets.js`, `docs/contract.md`.

## 0.2.0a1 — `ds-webui-0.2.0a1.tar.gz`

Пофакторные фильтры в шапке таблицы — применение по требованию, а не посимвольно.

- Ввод в поле фильтра столбца больше не фильтрует на каждый символ. Условие набирается
  целиком и применяется по `Enter` или по кнопке-воронке, добавленной в конце поля справа.
  `Esc` — отменить несохранённый ввод. Пустое поле + `Enter` — снять фильтр столбца.
- Пока ввод не применён, поле подсвечено (класс `dirty`) — видно, что есть неприменённое
  изменение. После применения фокус остаётся в поле — можно уточнять.
- Только `app.js` (`renderGrid`) и `styles.css`; поведение датасета и контракт не менялись.

## 0.1.0a1 — `ds-webui-0.1.0a1.tar.gz`

Первая альфа. Рабочая вьюшка поверх файлового контракта `ds` → `ds-webui`.

- Две страницы: **Таблица** (широкая таблица, пофакторные фильтры, группировка со
  сворачиванием, «скрыть пустые колонки», экспорт в `.xls` и `CSV` — всё клиентски) и
  **Конструктор выборки** (выбор источников/показателей, срез `as_of`, межисточниковый
  LEFT JOIN, подстрочные фильтры, пресеты).
- Полностью serverless: статические `index.html` + `.js`, работает как `file://`, без сети.
  Манифест грузится инъекцией `<script>` с fallback `data/` → `sample-data/`.
- `presets.js` — базовый пресет; последний использованный запоминается в `localStorage`.
- `sample-data/` — настоящий вывод `ds get` из двух источников (один свежий, один
  намеренно устаревший — чтобы был виден бейдж «пересобрать»).
- `scripts/` — макросы офисного пакета (`export_full.py`, `export_diff.py`, `common.py`):
  выгрузка листа целиком или только правок в JSON по неймингу `ds-loader`.
- Файловый контракт — `docs/contract.md`. Данные во вьюшку кладёт стадия `publish`
  загрузчика `ds-loader` (>= 0.4.0a1).
- Не реализовано: drag-and-drop пресета, вычисляемые/семантические показатели, поллер
  (роль поллера сейчас исполняет `ds-loader`).
